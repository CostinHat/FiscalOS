# Review Checklist

Use this checklist before accepting future changes to the documentation set.

- [ ] No document assigns repository IDs as canonical identity.
- [ ] No document treats content hashes as complete raw document identity.
- [ ] No document treats legal references as generated rules.
- [ ] No document introduces AI/NLP scope.
- [ ] No document introduces graph implementation or traversal.
- [ ] No document introduces persistence or API implementation.
- [ ] Snapshots remain immutable and versioned.
- [ ] Provenance and audit remain distinct.
- [ ] Corrections and replay outcomes remain additive.
- [ ] Unresolved and ambiguous resolution outputs remain first-class outcomes.
- [ ] Downstream consumers remain readers/projection owners, not canonical owners.
