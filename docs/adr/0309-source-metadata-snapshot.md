# FOS-0309 Source Metadata Snapshot Model

Status: accepted.

## Decision

Define immutable source metadata snapshots for acquisition-time source context.

## Captures

- Source ID.
- Display metadata.
- Authority metadata.
- Source capabilities.
- Adapter version.
- Acquisition context.
- Configuration snapshot linkage.

## Boundaries

The snapshot does not replace source identity and does not build source hierarchy.
