# FOS-0319 Resolution Policy Model

Status: accepted.

## Decision

Define versioned deterministic policies for reference resolution attempts.

## Policy Areas

- Input requirements.
- Candidate matching rules.
- Target selection rules.
- Ambiguity handling.
- Unresolved handling.
- Replay and rerun behavior.

## Boundaries

Policies do not normalize references, build source hierarchy graphs, use AI/NLP, or generate rules.
