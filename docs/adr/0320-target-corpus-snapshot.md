# FOS-0320 Target Corpus Snapshot Model

Status: accepted.

## Decision

Define target corpus snapshots as immutable, repository-neutral context for resolution attempts.

## Captures

- Corpus scope.
- Included target kinds.
- Included jurisdictions and authorities.
- Included document/reference sets.
- Source hierarchy context reference.
- Corpus completeness status.

## Boundary

The snapshot identifies available targets; it does not resolve references.
