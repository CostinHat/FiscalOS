# FOS-0316 Legal Reference Identity Model

Status: accepted.

## Decision

Define legal reference identity separately from raw document, source, repository, and future rule identity.

## Responsibilities

- Preserve raw reference text.
- Preserve normalized reference text.
- Link reference candidates to raw document versions.
- Preserve unresolved and ambiguous references.
- Support correction, replay, and audit.

## Boundaries

A legal reference is not a raw document and does not imply a rule.
